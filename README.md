# AI Waste-Worthy

**Turn a photo of waste into a step-by-step recycling/upcycling recipe.**  
Upload an image → CNN classifies the waste → app returns a detailed, practical guide + safety tips.

## Features
- Image-based waste classification (CNN)  
- Returns step-by-step conversion / upcycling instructions  
- Confidence score and safety notes - REST API for programmatic use

## Tech Stack
- Frontend: (React / simple HTML)  
- Backend:  Flask  
- Model: PyTorch/TensorFlow CNN (e.g., ResNet / MobileNet)  
- Storage: JSON  for recipe mapping

## Model & Data
- one is free to input any type of image size and our model is trained to process it
